# fan-tray

Lightweight C++ GTK3 + Ayatana AppIndicator3 system tray widget for Linux to monitor **Chassis Fan 3 (RPM)** and **NVIDIA Tesla V100 temperature**, with a one-click **Turbo Mode (100% Fan)** toggle.

## Build & Run

```bash
sudo apt install -y libgtk-3-dev libayatana-appindicator3-dev
make
./fan-tray
```
